# DotNet Patterns Lab

A .NET 10 Web API learning workspace for design patterns.

## Workspace structure

Creational patterns:

1. Singleton
2. Factory Method
3. Abstract Factory
4. Builder
5. Prototype

Structural patterns:

1. Adapter
2. Decorator
3. Facade
4. Composite
5. Proxy
6. Bridge
7. Flyweight

Behavioral
 
1. Observer
2. Strategy
3. Command
4. Iterator
5. Mediator
6. State
7. Template Method
8. Chain of Responsibility
9. Visitor
10.Interpreter
11.Memento

Each pattern keeps its own solution, source variants, and dedicated NUnit tests under its `tests/` folder.
