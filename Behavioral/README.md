# Behavioral

This folder contains behavioral design patterns implemented as .NET Core Web API learning samples.

Patterns included:

1. Observer
2. Strategy
3. Command
4. Iterator
5. Mediator
6. State
7. Template Method
8. Chain of Responsibility
9. Visitor
10. Interpreter
11. Memento

Each pattern folder follows the same overall structure used across the repository: a solution per pattern, Web API-based samples, and supporting test documentation.
